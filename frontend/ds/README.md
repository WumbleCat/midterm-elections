# Industry design system (vendored)

`industry.css` is a verbatim copy of `styles.css` from the Claude Design project
`b005845c-c592-4a23-89f3-d40b670da986` (`_ds/industry-1045886b-…/styles.css`).
It is the single source of truth for colour, type, spacing, radius and shadow:
take every value from its variables (`var(--color-*)`, `var(--font-*)`,
`var(--space-*)`, …) and build with its classes (`.blueprint` + `.corner`,
`.btn`, `.seg`/`.seg-opt`, `.input`, `.table`, `.tag`, `.nav`) rather than
inventing parallel ones.

Do not edit this file by hand — re-sync it from the design project when the
system changes (see `.claude/skills/election-explorer/SKILL.md`).

Direction, in short: a light technical ground, one steel-blue accent, Barlow
Condensed headings over Barlow body, square corners everywhere, cards and
figures drawn as hairline "blueprint" frames with `+` registration marks, and
Lucide icons at stroke-width 1.5.
